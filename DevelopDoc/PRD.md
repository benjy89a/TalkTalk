# PRD — TalkTalk 제품 요구사항

> 상태: **최종** (11/24 실제 구현 범위로 갱신) · 시연 URL: https://talk-talk-gold.vercel.app
> 구현 표시: ✅ 완료 · 🟡 일부 · ❌ 미구현

## 1. 한 줄 요약
사내 구성원이 채널과 DM으로 실시간 대화하고, AI로 긴 대화를 빠르게 따라잡는 **업무용 채팅 서비스**.

## 2. 문제와 목표
| 문제 | 목표 |
|---|---|
| 업무 대화가 개인 메신저에 흩어져 있다 | 팀 대화를 채널 단위로 한곳에 모은다 |
| 주제별 대화가 섞여 흐름을 놓친다 | 스레드로 주제별 답글을 분리한다 |
| 자리를 비운 사이 쌓인 메시지를 다 읽기 어렵다 | 미읽음 표시 + AI 요약·할 일 추출 |
| 예전 대화를 다시 찾기 어렵다 | 키워드 검색 + 자연어 검색 → 결과에서 그 메시지로 바로 이동 |

## 3. 사용자와 역할
- 하나의 회사(워크스페이스 1개)에 속한 직원
- 역할은 3단계 (`002_roles.sql`)
  - **서비스 관리자**: 공개 채널 만들기, 모든 채널 관리, 관리자 페이지(사용자·채널·AI 설정) 사용
  - **채널 관리자**: 채널을 만든 사람 또는 관리자로 지정된 사람. 멤버 초대·내보내기, 관리자 지정·해제, 채널 이름 변경·삭제
  - **일반 멤버**: 비공개 채널 만들기, 대화, 공개 채널 참여·나가기

## 4. 참고 제품
Mattermost 의 화면 구성과 흐름(사이드바 / 메시지 영역 / 스레드 패널)을 참고한다. 코드는 사용하지 않는다.

## 6. 비기능 요구사항
- 메시지는 보낸 뒤 1초 안에 다른 사용자 화면에 보인다.
- 다른 채널(내가 멤버가 아닌 비공개 채널·DM)의 메시지는 볼 수 없다 (DB 권한(RLS)으로 보장).
- AI·DB 비밀 키는 서버에서만 사용하고 브라우저로 보내지 않는다.
- 데스크톱 브라우저(Chrome) 기준. 좁은 화면에서는 사이드바가 서랍처럼 열리고 스레드는 화면 전체로 열린다 (모바일 앱은 범위 밖).

## 7. 범위 밖
- 여러 워크스페이스(팀), 음성·영상 통화, 푸시 알림·소리 알림, 모바일 앱

## 8. 시연 시나리오 (발표용)
1. 두 브라우저에서 두 사용자로 로그인 → `#general` 에서 실시간 대화
2. 비공개 채널 만들고 동료 초대 / DM 보내기
3. 메시지에 답글 → 스레드 패널
4. 한쪽 사용자가 다른 채널에 있을 때 미읽음 굵게·멘션 배지
5. 파일 첨부, 이모지 반응, 메시지 수정·삭제
6. 검색 → 결과를 눌러 그 메시지로 이동
7. AI 요약·AI 검색 (응답이 늦을 때를 대비해 녹화 영상 준비)
