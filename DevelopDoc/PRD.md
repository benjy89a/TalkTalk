# PRD — TalkTalk 제품 요구사항

> 상태: **최종** (11/25 실제 구현 기준으로 갱신) · 시연 URL: https://talk-talk-gold.vercel.app
> 구현 표시: ✅ 완료 · 🟡 일부 · ❌ 미구현

## 1. 한 줄 요약
사내 구성원이 채널과 DM으로 실시간 대화하고, AI로 긴 대화를 빠르게 따라잡는 **업무용 채팅 서비스**.

## 2. 문제와 목표
| 문제 | 목표 | 구현한 해결 |
|---|---|---|
| 업무 대화가 개인 메신저에 흩어져 있다 | 팀 대화를 채널 단위로 한곳에 모은다 | 공개·비공개 채널, 1:1 DM |
| 주제별 대화가 섞여 흐름을 놓친다 | 스레드로 주제별 댓글을 분리한다 | 오른쪽 스레드 패널 |
| 자리를 비운 사이 쌓인 메시지를 다 읽기 어렵다 | 미읽음 표시 + AI 요약·할 일 추출 | 굵게·멘션 배지·알림 카드, AI 요약·할 일 추출 |
| 예전 대화를 다시 찾기 어렵다 | 키워드 검색 + 자연어 검색 | 검색 결과를 누르면 그 메시지로 이동·강조 |
| 누가 읽었는지, 지금 누가 있는지 모른다 | 읽음·접속 상태를 보여 준다 | 안 읽은 사람 수, 접속 중 초록 점, 입력 중 표시 |

## 3. 사용자와 역할
- 하나의 회사(워크스페이스 1개)에 속한 직원
- 역할은 3단계 (`supabase/migrations/002_roles.sql`)

| 역할 | 누가 | 할 수 있는 일 |
|---|---|---|
| **서비스 관리자** | `app_admins` 에 등록된 사람 | 공개 채널 만들기, 모든 공개 채널 관리, 관리자 페이지(사용자·채널·AI 설정) |
| **채널 관리자** | 채널을 만든 사람 또는 관리자로 지정된 사람 | 멤버 초대·내보내기, 관리자 지정·해제, 채널 이름 변경·삭제, 메시지 삭제 |
| **일반 멤버** | 가입한 모든 사람 | 대화, 비공개 채널·DM 만들기, 공개 채널 참여·나가기, 내 메시지 수정·삭제 |

> 비공개 채널·DM 은 서비스 관리자라도 멤버가 아니면 내용을 볼 수 없다 (사생활 보호).

## 4. 참고 제품
Mattermost 의 화면 구성과 흐름(사이드바 / 메시지 영역 / 스레드 패널)과 데이터 구조를 참고했다. 코드는 사용하지 않았다.
메시지 화면의 사용감(말풍선, 답장, 안 읽은 사람 수)은 카카오톡을 참고했다.

## 6. 비기능 요구사항
| 항목 | 기준 | 결과 |
|---|---|---|
| 실시간성 | 메시지는 보낸 뒤 1초 안에 다른 사용자 화면에 보인다 | ✅ 배포본 실측 0.48~0.96초 |
| 권한 | 내가 멤버가 아닌 비공개 채널·DM 의 메시지는 볼 수 없다 (DB 권한 RLS 로 보장) | ✅ |
| 비밀 키 | AI·DB 비밀 키는 서버에서만 사용하고 브라우저로 보내지 않는다 | ✅ |
| 성능 | 메시지 1만 건 채널에서도 화면이 멈추지 않는다 | ✅ 화면 최대 500개, 멈춤 최대 0.12초 |
| AI 대기 | AI 응답은 최대 240초까지 기다리고, 진행 시간 표시·취소 가능 | ✅ |
| AI 남용 방지 | 한 사람이 AI 를 연타·반복 호출하지 못한다 | ✅ 사용자별 동시 1건 · 분당 5회 |
| 화면 | 데스크톱 Chrome 기준. 휴대폰 크기에서도 깨지지 않는다 (말풍선 톡 → 버튼 줄) | ✅ |

## 7. 범위 밖
- 여러 워크스페이스(팀), 음성·영상 통화, 모바일 앱, 푸시(앱) 알림·소리 알림
- 프로필 사진(아바타), 사용자 삭제(관리자 페이지에서 지원하지 않음)
- 하루 단위·서비스 전체 AI 사용량 상한 (지금은 서버 메모리 기준 사용자별 분당 제한만)

## 8. 알려진 한계
- AI 응답 속도는 외부 업체 상태에 따라 수십 초~수 분으로 들쭉날쭉하다 → 시연은 녹화 영상도 함께 준비.
- AI 기능을 쓰면 선택한 대화와 작성자 이름이 외부 AI 서비스로 전송된다 (화면에 안내).
- 스레드 댓글에는 안 읽은 사람 수를 표시하지 않는다 (읽음 위치가 채널 본문 기준).
- 동시에 서로 DM 을 만들면 늦은 쪽에 한 번 오류가 뜨고, 다시 누르면 기존 DM 이 열린다.

## 9. 시연 시나리오 (발표용)
1. 두 브라우저에서 두 사용자로 로그인 → `#general` 에서 실시간 대화 (입력 중 표시, 안 읽은 사람 수 줄어드는 것)
2. 비공개 채널 만들고 동료 초대 → 상대 화면에 초대 알림 카드 / DM 보내기
3. 메시지에 스레드 댓글 → 오른쪽 패널, 이모지 반응, 답장 인용, 수정·삭제
4. 한쪽 사용자가 다른 채널에 있을 때 `@멘션` → 미읽음 굵게·멘션 배지·알림 카드 → 카드 눌러 이동
5. 파일·이미지 첨부 (캡처 붙여넣기 → 이미지 눌러 크게 보기)
6. 키워드 검색 → 결과를 눌러 그 메시지로 이동
7. ✨ AI 도구: 대화 요약 · AI 검색 · 할 일 추출 (응답이 늦을 때를 대비해 녹화 영상 준비)
8. 관리자 페이지: 사용자·채널 관리, AI 업체 전환
