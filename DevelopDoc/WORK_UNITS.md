## B — 계섭: 메시지 코어

### B-1. 메시지 목록 표시 (F-20)
- [ ] 선택한 채널의 메시지를 최근 50개 불러와 오래된 순으로 표시
- [ ] 보낸 사람 이름(profiles.name), 시간 표시
- [ ] `parent_id is null` 인 메시지만 본문에 표시

### B-2. 메시지 전송 + 멱등 (F-20, F-21)
- [ ] 입력창 Enter 로 전송, Shift+Enter 줄바꿈
- [ ] `client_id = crypto.randomUUID()`, 재시도 시 같은 값 사용
- [ ] 전송 버튼 연타 / 재시도에도 DB 에 한 건만 저장됨을 확인
- [ ] 전송 중 표시 → 저장되면 정상 표시, 실패하면 "재전송" 버튼

### B-3. Realtime 수신 (F-20)
- [ ] 다른 브라우저에서 보낸 메시지가 새로고침 없이 1초 안에 표시
- [ ] 채널을 바꾸면 이전 채널 구독 해제
- [ ] 내가 보낸 메시지가 두 번 보이지 않음 (client_id 로 중복 제거)

### B-4. 델타 동기화 (F-22)
- [ ] 채널별 마지막 수신 id 기억
- [ ] 와이파이 끄고 → 다른 사람이 메시지 보냄 → 와이파이 켜면 놓친 메시지만 받아옴

### B-5. 스레드 (F-24)
- [ ] 메시지에 "답글" 버튼, 답글 수 표시
- [ ] 클릭하면 오른쪽 스레드 패널에 root + 답글 목록
- [ ] 스레드 패널에서 답글 전송 (parent_id 설정), 실시간 반영

### B-6. 무한스크롤 (F-23)
- [ ] 맨 위로 스크롤하면 이전 50개 추가 로드
- [ ] 로드 후 스크롤 위치가 튀지 않음
