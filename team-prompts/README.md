## 모든 파일 공통 구성
0. **준비물**: Node.js 24, Git, Claude Code 설치 (사람이 직접)
1. **세팅 프롬프트**: 레포 받기 → 패키지 설치 → `.env.local` → 실행 (처음 한 번만)
2. **매일 시작 프롬프트**: Claude를 새로 켤 때마다 맨 처음에 붙여넣기
3. **작업 프롬프트**: WORK_UNITS 의 작업 단위를 하나씩
4. **마무리 프롬프트**: 커밋 → push → PR

## 팀 공통 약속 (통합할 때 서로 맞물리도록)
- 컴포넌트는 필요한 값(`channelId`, `rootId` 등)을 **props 로 받게** 만든다.
  "지금 어떤 채널이 선택됐는지"를 화면 전체에 연결하는 일은 **팀장이 통합 때** 한다.
- 다른 사람 기능이 아직 없으면 기다리지 말고 **임시 값(가짜 데이터)** 으로 화면부터 만든다.
- 로그인은 C 가 Day 1 오전에 가장 먼저 만든다 → 머지되면 단톡방에 알린다.
  (그 전에는 Supabase 대시보드에서 만든 테스트 계정으로 확인 불가 → 화면 위주로 작업)
