## 파일별 하는 일

| 파일 | 하는 일 |
|---|---|
| `types.ts` | 메시지와 보낸 사람 이름을 묶은 모양, 한 번에 50개 불러오기 설정 |
| `format.ts` | "오후 3:42" 같은 시간 표시, 날짜 구분선 글자("11월 23일 월요일"), 5분 안에 같은 사람이 보낸 메시지 묶기 규칙 |
| `useChannelMessages.ts` | 채널의 최근 메시지 50개를 불러옴(답글은 빼고 본문만). 새 메시지를 실시간으로 받고, 채널이 바뀌면 이전 구독을 끊음. 실시간 메시지의 보낸 사람 이름은 따로 한 번 불러와 기억. **(B-4)** 채널별 마지막 수신 id 를 기억했다가 다시 연결되면(실시간 재연결 · 탭 복귀 · 와이파이 복구) 그 id 이후 메시지만 500개씩 끝까지 받아옴 |
| `outbox.ts` | "보내는 중인 메시지" 공유 보관함. 입력창과 목록이 화면의 서로 다른 칸에 있어도 같은 데이터를 봄. 보내는 즉시 화면에 표시 → 저장되면 확정, 실패하면 재전송(같은 `client_id`). **(B-4)** 다시 연결되면 실패한 메시지 자동 재전송 |
| `MessageInput.tsx` | 메시지 입력창. Enter 전송 · Shift+Enter 줄바꿈 · 최대 6줄까지 늘어남 · 4000자 제한 · 한글 조합 중 Enter 무시 |
| `MessageItem.tsx` | 메시지 말풍선 한 개. 내 메시지는 오른쪽 남색, 상대방은 왼쪽 회색(묶음 첫 줄에 아바타·이름). 시간은 묶음 마지막 말풍선 옆. 보내는 중은 흐리게, 실패하면 "재전송 · 삭제" |
| `MessageList.tsx` | **(읽음)** D 의 `useMarkAsRead` 로 DB 에 저장된 마지막 메시지 id 까지 읽음 처리(보내는 중 메시지 제외). 메시지 목록 + 날짜 구분선 + 불러오는 중 / 메시지 없음 / 실패 시 "다시 시도". 맨 아래를 보고 있을 때만 자동 스크롤, 위를 읽는 중이면 "새 메시지 n개 ↓" 버튼, 연결 끊김 띠 |
| `useCurrentUserId.ts` | 지금 로그인한 사람의 id (내 메시지를 오른쪽에 보여주기 위해) |

## 사용법 (화면에 끼울 때 — 팀장님 참고)

```tsx
import MessageList from "@/components/chat/MessageList";
import MessageInput from "@/components/chat/MessageInput";

// components/layout/MessageArea.tsx 의 B 자리(Placeholder)에
<MessageList channelId={선택된채널id} />   // 메시지 목록 칸
<MessageInput channelId={선택된채널id} />  // 입력창 칸

// 스레드 답글 입력창 (B-5 에서 사용)
<MessageInput channelId={채널id} parentId={원본메시지id} />
```

- `MessageList` 는 부모 칸이 `flex flex-col` 이고 높이가 정해져 있어야 안에서 스크롤됩니다.
- 둘은 `outbox.ts` 로 연결되어 있어서 따로 이어줄 필요가 없습니다.
